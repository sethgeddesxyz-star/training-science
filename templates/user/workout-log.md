# Workout Log

Running log of all completed workouts. Most recent sessions at the bottom. Updated after every workout.

---

## Log Format

```
## YYYY-MM-DD — [Location] ([Split Label])

### Working Sets
- [Exercise]: [weight] × [reps], [reps], [reps] ([effort])
  > [Any notes]
```

**Effort key**: easy = RIR 4+ | good = RIR 2-3 | hard = RIR 0-1 | failed = missed reps
