- **Required prehab** (every lifting day, 2 rounds):

  - Band External Rotation — 12/side

---

## Prehab Placement Rules

1. Prehab goes **first** (after general warmup, before working sets).
2. Light load / bands — activation, not training sets.
3. Runs as rounds (one set of every item per round), never as stacked consecutive sets.
4. Prehab sets do not count toward weekly volume.

---

## Pain Response Protocol

If the user reports pain during any exercise:

1. **Immediately stop that exercise** for the session
2. **Substitute** a pain-free alternative hitting the same muscle group
3. **Note in the workout log** which exercise caused pain
4. **Next session**: test with lighter weight and controlled tempo
5. **If pain persists across 2+ sessions**: exclude the exercise and flag for review
6. **The way back** (test session, ramp, exclusion and re-entry, what neighbouring lifts
   do) is `system/return-to-training.md`. Steps 1–5 are the trigger; that file is the rest.

Never push through joint pain. Muscle fatigue/burn is normal; sharp, stabbing, or
grinding sensations are not. Persistent pain is a reason to see a clinician.
