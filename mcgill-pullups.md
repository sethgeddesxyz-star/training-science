# McGill Pull-up Clusters (added 2026-10-13, user request)

Dr. Stuart McGill's pull-up method, fitted to the SBS block structure. It changes **how the
pull-up is trained in Strength blocks** and adds an optional primer in Hypertrophy blocks. It
does not touch the row (the pull-day main lift), the rotation, or any other lift.

Read this file when prescribing a day type that carries a vertical pull (`splits.md` §2:
PULL, UPPER, FB-A) and a pull-up or assisted pull-up is in the user's state. A user with no
pull-up in state does not need it (clarified 2026-10-25).

---

## 1. The method (short version — sources in §8)

- **Singles or doubles only, each one at maximum intent.** Not sets of 5–10. The goal is
  neural drive and whole-body stiffness, not fatigue. Fatigued high-rep pull-ups are where
  tendon strains (lats, pecs, biceps) come from.
- **Full reset between every rep.** Drop off the bar, let the arms hang loose, breathe out,
  breathe in, then set up again. Coaching write-ups of the method use 10–20 s between reps for
  advanced lifters; this program uses **20–30 s** until the cluster is easy.
- **Stiffness first, then explode.** Set up until motionless, then pull as fast as possible,
  hold the top for about 1 s, lower under control.
- **Stop the moment speed drops.** Quality ends the cluster, not a rep count.
- **Spine load is real.** McGill's lab measured pull-ups and chin-ups as the *highest*
  spine-load pulling exercises tested, despite hanging, because they need the most muscle
  activation. Coaching shoulder retraction raised spine load further while adding shoulder
  stiffness. So: never with an open back event (§5), and the brace is part of the lift.

### Setup cues (print these in the coaching view, first cluster of each block)
1. **Lobster-claw grip** — wrap the bar, lock the thumb down over the index finger, crush.
2. **Legs crossed and squeezed**, glutes tight, abs braced (the McGill brace: stiffen, don't suck in).
3. **Shoulder blades down and back** before the pull starts. Dead still.
4. **Explode up**, chin over the bar, hold ~1 s, lower slowly to a full hang.
5. A sharp exhale on the pull is fine.

**A rep does not count if anything wiggles**: legs uncross, pelvis swings, any kip or leg drive.

## 2. Where it fits in SBS

| Block / week | Pull-up treatment |
|---|---|
| **Strength Wk 1** | McGill cluster: **8 singles @ bodyweight**, strict bar |
| **Strength Wk 2** | **10 singles** |
| **Strength Wk 3** | **12 singles** |
| **Strength Wk 4** | **6 doubles** (or singles if the second rep slows) |
| Deload | **4 singles**, easy pace, or skip — not a miss |
| Hypertrophy blocks | Assisted Pull-up stays on **double progression** (§3 of the progression rules), unchanged. Optional **McGill primer: 3 singles @ BW** before the first warmup ramp |

**Why the Strength block.** SBS Strength blocks run heavy, low-rep work with long rest; McGill
clusters are the same idea for a bodyweight lift. A strict bodyweight pull-up for someone with
a ~4-rep max is already in the ~80–90% range, i.e. strength-block intensity, so no assist and
no added load are needed to start. Hypertrophy blocks need sets taken close to failure, which
the method deliberately avoids, so the assisted machine keeps that job.

**This replaces** the §6 branch-2 wave conversion for the Assisted Pull-up in Strength blocks
(4×5 / 4×4 / 5×3 / 3×2 on the offset scale). The assisted machine's banked offset is kept
untouched and resumes at the next Hypertrophy block.

**Position:** first working exercise on pull day, right after prehab, before the row's warmup
ramp. It is short (~5–6 min) and needs a fresh nervous system. The row stays the main lift; the
"never cut the first two working exercises" rule now protects the cluster and the row.

**Volume:** count a full cluster as **2 hard sets** of lat volume (1.0×) and 1 set of biceps
(0.5×). Strength-block maintenance targets (4–8 sets/muscle/week) are otherwise unchanged.

**Time limit:** never cut. If the day is very short, shrink it to 6 singles.

## 3. Progression

- **Clean cluster** = every prescribed rep crisp (fast up, no wiggle), no shoulder or back
  sensation. Clean → next week's number per the table.
- **Cluster ends early** (speed dropped) → the reps done count; **not a miss**. Repeat the same
  target next week instead of advancing. Two early endings in one block → next block starts
  one step lower (Wk 1 = 6 singles).
- **Across blocks:** when Wk 3 (12 singles) and Wk 4 (6 doubles) are both clean, the next
  Strength block adds load: **+5 lb** (backpack at home, dip belt or DB between the feet at the
  gym), same 8 → 10 → 12 → 6×2 wave. Keep adding 5 lb per block while both stay clean.
- **Calibration (first cluster ever).** The first single must be crisp. If it isn't (slow
  grind, or under 3 crisp singles), run the cluster on the **assisted machine at 40 lb offset**
  instead, same rules, and drop 15 lb of assist per block until bodyweight is reached.
- **No e1RM.** Bodyweight singles don't feed the Epley formula; track reps, load and whether
  the cluster was clean.

---

## 4. Home vs gym

Same prescription on the doorframe bar at home and the fixed bar at the gym. Use the overhand
(pull-up) grip by default. A neutral grip, if a bar offers one, is allowed when the shoulder
asks for it — log the grip.

---

## 5. Gates (checked before prescribing; injury file always wins)

- **Back:** no McGill cluster while a back Pain Response Protocol is open. That block runs the
  Assisted Pull-up on the §6 branch-2 conversion instead and the cluster starts at the next
  pull session after the protocol closes. (McGill's own rule of thumb, as relayed by coaches:
  not for anyone in current back pain.)
- **Shoulder (always-active flag):** any shoulder sensation ends the cluster → Pain Response
  Protocol for the pull-up, as for any exercise. No kipping, ever. Lower slowly into the hang;
  never drop into it.
- **Elbow/biceps:** an ache at the elbow ends the cluster for the day.

---

## 6. Checklist lines

A cluster is one line, not one line per single (the one-line-per-set rule's only exception —
twelve identical lines are noise):

```
McGill Pull-up — R20-30s between reps
McGill Pull-up — Cluster — BW — 8 × 1
```

The user edits the count to the number of crisp reps done (`6 × 1` = stopped after 6). A note
like "slowed on 7" is the stop reason. Unchanged = all prescribed reps crisp.

Hypertrophy primer: `McGill Primer — BW — 3 × 1` under WARMUP. Deleted = not done, not a miss.

---

## 7. What this file never does

- Never prescribes reps to failure or sets of more than 2.
- Never overrides an open Pain Response Protocol.
- Never changes the row's wave or the Assisted Pull-up's banked offset.
